## Authentication

### TC-001 — Verify successful login with valid credentials redirects to Dashboard
**Feature:** User Login · **Priority:** P0 · **Type:** positive · **Severity:** Critical

Confirms a registered user can authenticate with a valid username and password and is redirected to the Dashboard. This is the primary gateway to the application and blocks all HR activities if broken.

**Precondition:** A registered user account exists with username 'Admin' and password 'admin123'. The login page is reachable at the QA URL.

**Steps:**

1. Navigate to https://opensource-demo.orangehrmlive.com/web/index.php/auth/login → Expected: The login page loads displaying the OrangeHRM logo, Username field, Password field, Login button, and 'Forgot your password?' link
2. Enter 'Admin' into the Username field → Expected: The Username field shows 'Admin'; no validation error appears
3. Enter 'admin123' into the Password field → Expected: The Password field shows masked characters; no validation error appears
4. Click the 'Login' button → Expected: The user is authenticated and redirected to the Dashboard page within 3 seconds; the sidebar and Dashboard heading are displayed

**Expected Result:** The user is authenticated, a valid session is created, and the Dashboard page is displayed.

**Tags:** smoke, regression, auth
